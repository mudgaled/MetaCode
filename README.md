MetaCode is a full-stack web platform that gamifies competitive programming and enhances user engagement through immersive experiences. 
Inspired by LeetCode and Codeforces, it's designed to make coding fun and beginner-friend.

Key Features:
Code inside a 2D metaverse 
Enter the coding zone,game zone or store.
Purchase Avatars based on collected coins.
Compete with member of your communities and improve your skills.
Communicate via text,voice or video calls.


Tech Stack:
React.js – Frontend library for building dynamic and responsive UIs
Next.js – React framework for server-side rendering and routing
Tailwind CSS – Utility-first CSS framework for styling the frontend
Node.js – Backend runtime environment for server-side logic
Express.js – Web framework for building backend APIs
Socket.IO – Real-time communication for collaborative coding and messaging
MongoDB – NoSQL database for storing data.
Phaser.js-A robust and popular HTML5 game framework for building 2D games.

Steps for implementing the project:
